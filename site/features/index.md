# Feature overview

Choose a feature for its steps, examples, settings, and limitations. All Patches settings live under **Settings → Patches**.

## Write and edit

| Feature | What it adds |
| --- | --- |
| [Note Git diff](../reference/commands.md#compare-a-note-with-git) | On desktop, compare a note with its last commit and jump to changes from the editor margin. |
| [HTML tables](tables.md) | Convert between Markdown and HTML tables. Edit merged cells, grouped headers, and captions. |
| [Callouts](callouts.md) | Insert, edit, preview, and unwrap callouts. Tint code backgrounds and check GitHub compatibility. |
| [Math formatting](math-format.md) | Indentation and alignment for display math, preserving formulas. |

Patches 0.7.0 adds [desktop Git change markers and comparison](../reference/commands.md#compare-a-note-with-git), [brand logos for callouts](callouts.md#type-appearance) and [installed-font suggestions for HTML tables](tables.md#inline-code-font).

Version 0.6.0 introduced [HTML-to-Markdown conversion](tables.md#convert-an-html-table-to-markdown), [table code fonts](tables.md#inline-code-font), [callout type completion and paste](callouts.md#type-completion-and-paste), and [per-type callout icons and colors](callouts.md#type-appearance).

## Shape your notes

| Feature | What it adds |
| --- | --- |
| [Banners](banner.md) | Images, animations, and videos from your vault as note covers. |
| [File and folder icons](icons.md) | Lucide icons and Simple Icons brand marks with text, brand, preset, or custom colors. |
| [Line width](line-width.md) | Exact global width input and per-note overrides. |
| [Active line](active-line.md) | A margin marker and highlighted line number for the cursor’s line. |
| [Heading levels](heading-levels.md) | H1–H6 labels and optional [section numbering](heading-levels.md#heading-numbering) in 0.8.0. |
