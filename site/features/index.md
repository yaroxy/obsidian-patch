# Feature overview

Choose a feature for its steps, examples, settings, and limitations. All Patches settings live under **Settings → Patches**.

## Write and edit

| Feature | What it adds |
| --- | --- |
| [HTML tables](tables.md) | Visual editing, merged cells, grouped headers, captions, and Markdown-to-HTML conversion. |
| [Callouts](callouts.md) | Insert, edit, preview, unwrap, and check GitHub compatibility; tint code backgrounds. |
| [Math formatting](math-format.md) | Indentation and alignment for display math, preserving formulas. |

## Shape your notes

| Feature | What it adds |
| --- | --- |
| [Banners](banner.md) | Images, animations, and videos from your vault as note covers. |
| [File and folder icons](icons.md) | Lucide icons and Simple Icons brand marks with text, brand, preset, or custom colors. |
| [Line width](line-width.md) | Exact global width input and per-note overrides. |
| [Active line](active-line.md) | A margin marker and highlighted line number for the cursor’s line. |
| [Heading levels](heading-levels.md) | H1–H6 labels beside headings in reading and editing views. |

## Render and share
