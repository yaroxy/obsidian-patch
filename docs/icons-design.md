# 文件浏览器图标与配色

## 范围与来源

图标只用于文件浏览器。Lucide 来自 Obsidian 的 `getIcon` / `getIconIds`，提供与宿主一致的通用线框图标；Simple Icons 补充品牌标志。设置页的 Icon sources 说明分工并链接到两个官网；选择面板的每个结果和当前预览都标注来源。

2026-11-17 用户认可把颜色选择合并到 Change icon，并明确保留在线获取和已用图标缓存。Simple Icons 的轮廓来自指定版本的 `@iconify-json/simple-icons` JSON，品牌色来自该包 `info.json` 标注的上游 Simple Icons 版本的 `data/simple-icons.json`；只读取数据，不导入远程 JavaScript。版本解析、请求超时、离线缓存沿用已有策略；品牌色请求失败不阻止使用图标。Simple Icons 的 `hex` 是单色品牌色，不代表完整多色 Logo。

## 交互

Change icon 面板包含搜索结果、当前图标与来源预览、配色选项以及固定的 Apply/Cancel。选中结果时不关闭面板、不写入图标分配；Apply 一次保存图标和颜色，Cancel 放弃本次分配修改。资源加载仍可更新图标缓存。打开单项时预选当前图标；多项原有图标不同时默认保留各自图标，只选择颜色即可批量改色。

面板垂直居中，最大高度为 760 px，且上下至少各留 24 px；搜索结果在余下空间滚动，颜色与操作按钮不随结果滚动。覆盖宿主 SuggestModal 默认的 15vh 顶部偏移，避免它与面板高度相加后贴住窗口底部。原生回归检查覆盖 100%、150%、200% 界面缩放下的留白、结果滚动和 Apply 按钮的实际命中位置。

颜色可跟随文字、使用品牌色、使用红橙黄绿青蓝紫粉八个预设，或选择自定义色。预设保存色名并引用 Obsidian 主题变量，随主题变化；自定义色保存规范化的六位 HEX。Brand color 只在当前图标有颜色元数据时可选；缺少元数据时明确显示不可用。已有未指定颜色的图标保持跟随文字；新选择的品牌图标在元数据可用时默认使用品牌色，Lucide 默认跟随文字。已经明确选择的颜色在换图标时保留；品牌模式切换到 Lucide 后回到文字色。

多选对象的颜色不同，以独立的 `mixedColors` 状态表示，默认 **Keep colors**；换图标时保持每个对象原有配色，只有主动选择统一颜色才覆盖。该状态不能与尚未设置颜色混为一谈。搜索框的 Enter 仍选择图标，底部按钮的 Enter 则执行当前按钮；使用公开的子 Scope 按焦点路由，保留宿主搜索导航、Tab 和 Escape。

## 状态与渲染

`paths` 保持原有的路径到图标 ID 映射，`colors` 保存路径到配色选择，`brandColors` 与 `svgs` 按图标 ID 缓存已用资源。旧设置没有颜色字段时默认空映射，不批量改色。重命名文件夹时同时移动图标和颜色的路径；移除图标同时清理颜色及不再使用的资源缓存。missing files 指仍有分配但实际路径已不存在的条目，清理只删除插件记录，不删除文件。

文件浏览器继续用静态 CSS 和编码后的 SVG 图像蒙版渲染，显式颜色写到该行的 `--obsidian-patch-icon-color`，文字色不覆盖现有继承值。回收、移除、跨窗口移动或卸载行节点时同时清理蒙版和颜色。没有动态样式表或内联 SVG DOM。卸载后到达的网络响应不能再修改设置。
